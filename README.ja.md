# ルビふりゃ～定食
![](assets/02_result.jpg)


- コピーした日本語にルビを振って表示する、Windows向けのアプリです。
- Webページやテキストなどから文章をコピーまたはカットすると、ルビ付きで表示します。
- アプリのバーは、タスクバーのようにデスクトップの端に表示されます。
- バーは画面の上下左右に配置でき、必要に応じて表示・非表示を切り替えられます。
- HTMLや青空文庫などの執筆に便利な、タグ付きコピー機能を搭載しています。
- バーに表示された文章の単語にマウスカーソルを合わせると、和英辞書の内容がポップアップ表示されます。
- 基本の辞書は内蔵されているため、オフラインでも動作します。

## 基本の使い方
1. `定食_main.exe` を起動します。アプリはタスクトレイに常駐し、画面上端にバーを表示します。
2. ルビを付けたい文章を、普段使っているアプリでコピーします。
3. コピーした文章がバーに表示され、ルビ付きの表示に変換されます。
4. バーに表示された文章の単語にマウスカーソルを合わせると、簡易的な和英辞書がポップアップ表示されます。
5. バーが不要なときは、後述の方法で非表示にできます。

## ルビ表示のオン・オフ
次のいずれかでバーの表示を切り替えられます。

### マウス操作派の方
- マウスの `センターボタン（ホイール）` をクリックします。
### キーボード派の方
- キーボードの `Home` キーを押しながら `Space` キーを押します。
### その他
- バーの表示切り替えボタンを押します。
- タスクトレイアイコンを右クリックし、「表示」または「非表示」を選びます。

バーを非表示にすると、コピーした文章の取り込みも一時停止します。バーを再表示すると、取り込みを再開します。

## バーのボタン
![](assets/03_result.jpg)


バーには次の操作ボタンがあります。

1. **表示切り替え** — バーの表示・非表示を切り替えます。
2. **クリア** — 表示中の文章を消去します。
3. **コピー** — ルビ付きの文章をクリップボードにコピーします（設定したタグが挿入されます）。
4. **設定** — コピー時に挟まれるルビのタグ形式を設定します。
5. **辞書** — ポップアップ辞書の有効・無効を切り替えます。アイコンが赤いときは有効です。

## ポップアップ和英辞書

![](assets/04_result.jpg)

辞書が有効な状態で、バーに表示された文章の単語にマウスカーソルを合わせると、少し待ってから意味がポップアップ表示されます。カーソルを単語から外すと、ポップアップは少し待ってから閉じます。

辞書を一時的に使わない場合は、バーの辞書ボタンを押すと無効になります。もう一度押すと有効になります。

## バーの位置を変える
タスクトレイアイコンを右クリックし、「上に配置」「左に配置」「右に配置」「下に配置」から選びます。バーは選択した画面の端に表示されます。

## ルビの設定
バーの設定ボタンを押すと設定画面が開きます。ルビ付き文章を囲むタグと、ルビと本文を区切る文字を変更できます。画面内のプレビューで出力例を確認し、「保存」を押してください。変更は保存後に反映されます。

設定を変更しない場合は「キャンセル」を押します。

## ユーザー辞書
`dict.csv` を使って、単語ごとにルビを設定できます。ファイルは実行ファイルと同じフォルダーに置いてください。

ファイルはCSV形式で、各行を次の順に記述します。

```csv
単語, 単語の区切り, 読み, 品詞
```

単語の区切り数と読みの区切り数は一致させてください。一致しない行があるとユーザー辞書を読み込めず、変換時に初期化エラー（コード -3）になります。単語を区切らない場合は、読みも区切らずに記述してください。

例：
```csv
プロ生ちゃん,プロ 生 ちゃん,プロ ナマ チャン,人名
珠音ちゃん,珠音 ちゃん,タマネ チャン,人名
```

## フォント設定

表示フォントは `config.ini` を編集して設定できます。

```config.ini
[font]
Fname=meiryo
Fsize=16
Fstyle=0
```

`Fstyle` は次の値を指定します。

```
0 : 標準
1 : 太字
2 : イタリック体
3 : 太字＋イタリック体
```

## 終了
タスクトレイアイコンを右クリックし、「終了」を選びます。

`Home` キーを押しながら `Escape` キーを押して終了することもできます。

## Webコンポーネントについて
Microsoft Edge の WebView2 コンポーネントを使用しています。
これは **[webview2_hsp.dll](https://github.com/nyorotan/webview2_hsp_dll/blob/main/README.ja.md)** を利用して実装しています。
この DLL は、Go 言語から WebView2 を利用するためのインターフェース `go-webview2` をベースに、cgo を用いて作成されています。


## 注意事項
- 誤動作の原因となるおそれがあるため、他のクリップボード拡張ソフトとの併用はお控えください。
- 本アプリはクリップボードにコピーされた文章を読み取って動作します。
- コピーした文章はルビ変換のためにアプリ内で処理されます。変換結果を貼り付ける前に、内容を確認してください。
- ルビの読みは自動変換によるものです。固有名詞や文脈によっては、正しく変換されない場合があります。
